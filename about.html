About Me

단순히 동작하는 코드가 아닌,
근거 있는 구조를 설계하려는 개발자입니다.

Java와 Spring Boot 기반으로 웹 서비스를 개발하며, 단순한 기능 구현을 넘어 서비스 로직과 도메인 구조를 고려한 설계를 지향합니다.
관광 정보 서비스와 중고거래 웹 프로젝트를 통해 RESTful API 설계와 데이터 흐름을 경험했으며,
최근에는 이커머스 서비스의 핵심 기능을 벤치마킹한 프로젝트에서 정산 도메인을 중심으로 시스템 구조를 설계했습니다.
프로젝트를 진행하며 기능 구현 이후 발생하는 변경과 확장에 대응하기 위해서는 초기 설계와 테스트가 중요하다는 점을 체감했고,
이를 바탕으로 유지보수성과 안정성을 고려한 개발을 지향하고 있습니다.
실제 서비스 환경에서 신뢰할 수 있는 개발자로 성장하는 것이 목표입니다.
